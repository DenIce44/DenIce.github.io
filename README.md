# Automation QA Portfolio

A professional, responsive portfolio for an Automation QA Engineer. It is intentionally dependency-free and ready for GitHub Pages.

## Personalize before publishing

Search the project for these placeholders and replace them with truthful information:

- `Your Name`, `YOUR NAME`, and `YOUR_USERNAME`
- `you@example.com`, location, and work preference
- `XX%`, `XXX+`, `X yrs`, and all project links
- Tools you genuinely use (remove anything you cannot discuss in an interview)
- Project descriptions and quantified outcomes

Add your résumé as `resume.pdf`. Never publish private employer code, credentials, client data, or confidential screenshots.

## Recommended portfolio repositories

1. `ui-automation-framework` — Playwright + TypeScript, page/component objects, fixtures, tags, reports, and GitHub Actions.
2. `api-test-framework` — REST Assured + Java, reusable request clients, schemas, test data builders, and reports.
3. `performance-testing` — k6 scenarios, thresholds, environment configuration, and readable results.

Each repository should include a concise README, architecture notes, setup instructions, sample reports, CI status badge, and a short list of engineering decisions.

## Publish with GitHub Pages

1. Create a public GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload these files to the repository root and commit them.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your portfolio will appear at `https://YOUR_USERNAME.github.io` after GitHub finishes deployment.

## Local preview

Open `index.html` in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
