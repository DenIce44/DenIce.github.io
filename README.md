# Denys Ishchuk — QA & Automation Portfolio

A professional, responsive portfolio presenting four years of hands-on QA experience, team leadership, performance testing, and growing automation expertise. It is dependency-free and ready for GitHub Pages.

## Final details before publishing

The main content is personalized. Optionally add a professional email, location/work preference, résumé, and measurable results that you can confidently explain in an interview. Never publish employer code, credentials, client data, or confidential screenshots.

## Recommended portfolio repositories

1. `ui-automation-framework` — Playwright + TypeScript, page/component objects, fixtures, tags, reports, and GitHub Actions.
2. `api-test-framework` — REST Assured + Java, reusable request clients, schemas, test data builders, and reports.
3. `performance-testing` — k6 scenarios, thresholds, environment configuration, and readable results.

Each repository should include a concise README, architecture notes, setup instructions, sample reports, CI status badge, and a short list of engineering decisions.

## Publish with GitHub Pages

1. Create a public GitHub repository named `DenIce44.github.io`.
2. Upload these files to the repository root and commit them.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your portfolio will appear at `https://denice44.github.io` after GitHub finishes deployment.

## Local preview

Open `index.html` in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
